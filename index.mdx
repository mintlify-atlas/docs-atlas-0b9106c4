EVerest is the open-source firmware stack for EV charging stations, backed by [Linux Foundation Energy](https://lfenergy.org/). Its modular, microservice-like architecture lets you build a full charging station software stack from interchangeable modules — connecting everything from hardware BSPs and powermeters to OCPP backends and ISO 15118 high-level communication.

## What EVerest Provides

EVerest handles the hard work of translating EV charging standards into working, tested code so that every car works with every charger and every charging network.

<CardGroup cols={3}>
  <Card title="Protocol Support" icon="tower-broadcast">
    OCPP 1.6, 2.0.1 & 2.1 · ISO 15118-2, -3, -20 · IEC 61851 · DIN SPEC 70121
  </Card>
  <Card title="Hardware Drivers" icon="plug">
    BSPs, powermeters, isolation monitors, DC power supplies, RFID/NFC readers, payment terminals
  </Card>
  <Card title="Energy Management" icon="bolt">
    Local energy management, PV integration, grid support, V2G, and external energy limit APIs
  </Card>
  <Card title="Stable APIs" icon="webhook">
    EVerestAPI (MQTT/AsyncAPI 3.0) and JSON-RPC WebSocket API for external application integration
  </Card>
  <Card title="Multi-language Modules" icon="code">
    Write modules in C++, Python, JavaScript, or Rust using the same interface model
  </Card>
  <Card title="Embedded Ready" icon="server">
    Yocto support, OTA updates, TPM-secured communication, and OpenSSF security compliance
  </Card>
</CardGroup>

## Get Started

<Steps>
  <Step title="Install dependencies">
    Set up a Linux build environment (Ubuntu 24.04+, OpenSUSE, or Fedora) with CMake, Boost, and other required libraries.
  </Step>
  <Step title="Clone and build EVerest">
    Clone the EVerest repository and build it with CMake. All C++ dependencies are pulled in automatically via CPM.
  </Step>
  <Step title="Run a simulation">
    Use one of the included SIL (simulation-in-the-loop) configurations like `config-sil.yaml` to run a full charging station simulation on your PC.
  </Step>
  <Step title="Integrate your hardware or backend">
    Connect EVerest to your OCPP CSMS, ISO 15118 PKI, or custom hardware by configuring the appropriate modules.
  </Step>
</Steps>
